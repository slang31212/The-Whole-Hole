# MPSS Contradiction Audit — folder contents

Audit of: "A Breakthrough in Semi-Submersible Design" (A.C. Lang, Seaways Engineering, 1988), 36-page scanned report.

- audit_report.md        The audit: verdict, contradictions (with locations/values/explanations), and claims that held up.
- ledger.md              The full evidence ledger — every number/date/claim extracted, its page/figure location, and each cross-check.
- pages/                 All 36 report pages rendered to PNG (page-0NN.png), the extracted text layer per page (page-0NN.txt, empty = scanned), and manifest.json.
- figures/               High-resolution crops of Figure 3 (the master dimensions table) used to read the displacement figure precisely.

Cited page numbers in the report are the document's OWN printed page numbers (printed page = PDF page - 6).
